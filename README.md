# BanglaSmartTools — Icon Set
![App Icon](./brand/app-icon.png)
## Contents
- `brand/` — Logo mark, App icon (512/192px), Apple touch icon (180px), Favicon (32/16px), in both PNG and SVG
- `png-512/` — 58 tool/category icons, transparent background, 512×512px PNG
- `svg/` — Same 58 icons as scalable, editable SVG source (edit colors/gradients easily)

## Style
Rounded-square gradient tile + bold white glyph + soft highlight/shadow — a flat/vector "premium SaaS" style.
Colors follow the category system: Calculator=Blue, Finance=Green, Text=Purple, PDF=Red, Image=Orange,
AI=Teal, Developer=Navy, Network=Cyan, Security=Violet, Design=Pink, QR=Turquoise, File=Emerald,
Video=Orange(alt), Audio=Rose, Utility=Red(alt), Business=Gold.

## Note
This is a hand-built vector/gradient icon system, not an AI-rendered photoreal image — chosen so every
icon is crisp, editable (SVG), and consistent at any size, including small favicon sizes.
